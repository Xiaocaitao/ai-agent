# `edit_file` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增基于唯一旧文本替换的 `edit_file`，并让 `write_file` 只能创建新文件。

**Architecture:** 两个公开工具保持独立职责，共用一个内部原子写入模块。`write_file` 通过临时文件加硬链接发布，保证目标存在时不覆盖；`edit_file` 读取并验证唯一旧文本后，通过临时文件加 `rename` 原子替换。

**Tech Stack:** TypeScript、Node.js 22 `node:fs/promises`、Node Test Runner、AJV JSON Schema。

## Global Constraints

- 每个实现阶段完成后停止，等待用户 Review。
- `write_file` 只创建新文件，目标存在时失败。
- `edit_file` 只修改已有 UTF-8 文件，不创建文件。
- `old_text` 必须非空且恰好出现一次，重叠匹配也算多次。
- `new_text` 可以为空字符串。
- 匹配使用普通字符串，不使用正则表达式。
- 两个工具都使用 `ask` 权限，授权精确到工具名和规范化文件路径。
- 不修改 `run_command`、Runtime、数据库、会话持久化和 macOS Seatbelt。
- 不覆盖或提交工作区中与本功能无关的已有改动。

- [ ] **Step 1: 新增内部原子写入模块**

实现：

```ts
import { link, open, rename, rm } from "node:fs/promises";
import path from "node:path";
import { randomUUID } from "node:crypto";

async function writeTemporaryFile(
  target: string,
  content: string,
): Promise<string> {
  const temporaryPath = path.join(
    path.dirname(target),
    `.agent-${randomUUID()}`,
  );
  const file = await open(temporaryPath, "wx");
  try {
    await file.writeFile(content, "utf8");
    await file.close();
    return temporaryPath;
  } catch (error) {
    await file.close().catch(() => undefined);
    await rm(temporaryPath, { force: true }).catch(() => undefined);
    throw error;
  }
}

export async function createFileAtomically(
  target: string,
  content: string,
): Promise<void> {
  let temporaryPath: string | undefined;
  try {
    temporaryPath = await writeTemporaryFile(target, content);
    try {
      await link(temporaryPath, target);
    } catch (error) {
      if (
        error instanceof Error &&
        "code" in error &&
        error.code === "EEXIST"
      ) {
        throw new Error("目标文件已存在，write_file 只能创建新文件");
      }
      throw error;
    }
  } finally {
    if (temporaryPath) {
      await rm(temporaryPath, { force: true }).catch(() => undefined);
    }
  }
}

export async function replaceFileAtomically(
  target: string,
  content: string,
): Promise<void> {
  let temporaryPath: string | undefined;
  try {
    temporaryPath = await writeTemporaryFile(target, content);
    await rename(temporaryPath, target);
    temporaryPath = undefined;
  } finally {
    if (temporaryPath) {
      await rm(temporaryPath, { force: true }).catch(() => undefined);
    }
  }
}
```

- [ ] **Step 2: 让 `write_file` 使用仅创建接口**

```ts
import { mkdir } from "node:fs/promises";
import path from "node:path";

import { failure, success, workspacePath } from "./_common.ts";
import { createFileAtomically } from "./_atomic_write.ts";

export async function writeFileTool(filePath: string, content: unknown) {
  if (typeof content !== "string") return failure("content 必须是字符串");
  try {
    const [target, relativePath] = await workspacePath(filePath);
    await mkdir(path.dirname(target), { recursive: true });
    await createFileAtomically(target, content);
    return success({
      path: relativePath,
      bytes_written: Buffer.byteLength(content, "utf8"),
    });
  } catch (error) {
    return failure(error);
  }
}

export const write_file = ({ path, content }: Record<string, unknown>) =>
  writeFileTool(String(path ?? ""), content);
```

- [ ] **Step 1: 新增 `edit_file` 实现**

实现：

```ts
import { readFile } from "node:fs/promises";

import { failure, success, workspacePath } from "./_common.ts";
import { replaceFileAtomically } from "./_atomic_write.ts";

export async function editFileTool(
  filePath: string,
  oldText: unknown,
  newText: unknown,
) {
  if (typeof oldText !== "string" || oldText.length === 0) {
    return failure("old_text 必须是非空字符串");
  }
  if (typeof newText !== "string") {
    return failure("new_text 必须是字符串");
  }

  try {
    const [target, relativePath] = await workspacePath(filePath);
    const content = await readFile(target, "utf8");
    const firstMatch = content.indexOf(oldText);
    if (firstMatch === -1) {
      return failure("old_text 在文件中未找到");
    }
    if (content.indexOf(oldText, firstMatch + 1) !== -1) {
      return failure(
        "old_text 在文件中出现多次，请提供包含前后文的唯一旧文本",
      );
    }

    const updatedContent =
      content.slice(0, firstMatch) +
      newText +
      content.slice(firstMatch + oldText.length);
    await replaceFileAtomically(target, updatedContent);
    return success({
      path: relativePath,
      replacements: 1,
      bytes_written: Buffer.byteLength(updatedContent, "utf8"),
    });
  } catch (error) {
    return failure(error);
  }
}

export const edit_file = ({
  path,
  old_text,
  new_text,
}: Record<string, unknown>) =>
  editFileTool(String(path ?? ""), old_text, new_text);
```
